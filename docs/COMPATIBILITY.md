# 兼容性说明

## 聊天签名与聊天插件（Forge 1.20.1）

| 场景 | 行为 |
|------|------|
| 不含宏的普通聊天 | 不进入 ItemShowcase 处理流程，原版签名广播完全保留 |
| 含宏的聊天 | 服务端取消原版聊天广播（`ServerChatEvent.setCanceled`），按接收者能力自行分发 |
| ItemShowcase 客户端接收者 | 收到 `SHOWCASE_MESSAGE` 结构化包（真实图标渲染） |
| 原版客户端接收者 | 收到可读回退文本（物品名 + 原版 show_item 悬停 Tooltip） |

**已知权衡（文档化，规范允许）：**

1. 含宏消息取消后以系统消息形式广播：聊天签名对该消息失效，
   1.20.1 原版客户端会将其显示为普通系统消息（可读，无"无法验证"警告）。
2. 服务端广播范围为全服玩家。第三方聊天插件（如频道类插件）对含宏消息的
   接收者过滤不生效；不含宏的消息不受任何影响。
   后续版本可探索直接改写事件消息内容而非取消事件的方案。

## 可选 MOD 依赖

| MOD | 状态 | 行为 |
|-----|------|------|
| Sophisticated Backpacks | 计划（阶段三） | 未安装时 `[i]`/`[pack]` 对背包物品按普通物品展示 |
| Curios API | 计划（阶段三） | 未安装时 `[c]` 显示"未安装饰品 API"提示 |
| Trinkets API | 计划（阶段三，Fabric） | 同上 |
| Accessories API | 计划（阶段三，1.21.1） | 同上 |

任何集成缺失都不会导致崩溃或功能删除，只是对应宏的展示范围缩小。

## 渲染说明

- 图标默认 16×16（GuiGraphics 坐标系），使用原版 ItemRenderer 真实模型，
  支持附魔光效、耐久条、数量覆盖、自定义模型与 BEWLR。
- 聊天行高为 9px，16px 图标在垂直方向略溢出行块（与主流聊天头像类 MOD 一致），
  客户端配置可将 `iconSize` 调整为 8-32。
- 极端情况下（聊天行宽恰好落在占位区中间）物品占位可能被折行拆开，
  该物品图标退化为空白、悬停失效，物品名文字仍完整可读（已知限制，持续改进）。
